# Проект: настройка Claude Code

Это рабочая папка для управления моей глобальной настройкой Claude Code: плагины, сабагенты, правила, модели. Сам код здесь не пишется — здесь меняется и документируется конфигурация.

## Где что лежит

Живые файлы (действуют на все чаты):
- `~/.claude/settings.json` — режим плана по умолчанию, модель (opus, effort medium), включённые/выключенные плагины.
- `~/.claude/CLAUDE.md` — глобальные правила: оркестрация агентов, раздел «Рекомендуемая настройка» в планах, каталог выключенного.
- `~/.claude/agents/` — сабагенты `implementer` (Sonnet), `quick-helper` (Haiku), `build-fixer` (Sonnet).
- `~/.claude/skill-library/` — скиллы «на полке», не грузятся (Taste Skill).

В этой папке:
- `README.md` — что настроено и шпаргалка команд (для меня).
- `docs/decisions.md` — журнал решений: что поставили, что отвергли и почему. **Читай перед тем, как предлагать изменения**, чтобы не предлагать то, что уже отвергли.
- `config-backup/` — копия живых файлов. Обновлять скриптом `backup.ps1`.
- `chat-archive/` — архив исходного чата настройки (`.jsonl`, искать по нему grep'ом, не читать целиком) и план оркестрации.

## Как работать в этом проекте

1. Любое изменение конфигурации — сначала план, потом правка живых файлов в `~/.claude/`.
2. После изменения: дописать запись в `docs/decisions.md` (дата, что, почему), обновить `README.md` если поменялось то, что я вижу, запустить `backup.ps1` (Linux: `backup.sh`), сделать git-коммит и `git push` (другие ноутбуки забирают изменения через `git pull` + `install`).
3. Перед установкой стороннего плагина/скилла — посмотреть его файлы (хуки, MCP, скрипты) и сказать, сколько он будет стоить контекста.
4. Список плагинов и их статус: `claude plugin list`; стоимость плагина: `claude plugin details <плагин>`.
