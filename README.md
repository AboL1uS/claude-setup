# Моя настройка Claude Code

Чтобы продолжить работу над настройкой — открой эту папку в VS Code и начни новый чат: Claude прочитает `CLAUDE.md` и журнал решений и будет в курсе всего.

## Как это работает

1. Каждый чат начинается в **режиме плана**: Claude изучает задачу и пишет план.
2. В конце плана — раздел **«Рекомендуемая настройка»**: какие шаги каким агентам, что включить, какую модель/effort.
3. Ты одобряешь — Claude (Opus) раздаёт рутину дешёвым агентам, сложное делает сам.

| Агент | Модель | Делает |
|---|---|---|
| implementer | Sonnet | обычный код по плану |
| quick-helper | Haiku | тесты/сборка, мелочи |
| build-fixer | Sonnet | чинит ошибки сборки |

## Включить выключенное в проекте

В папке проекта в терминале:
```
claude plugin enable impeccable@impeccable --scope project
```
Затем новый чат или `/reload-plugins`. Имена всех плагинов — в `docs/decisions.md`.

Taste Skill: скопировать `C:\Users\Ali\.claude\skill-library\design-taste-frontend` в `<проект>\.claude\skills\`.

## Шпаргалка команд в чате

| Команда | Зачем |
|---|---|
| `/clear` | начать с чистого листа (между задачами — главная экономия) |
| `/compact` | сжать длинный чат |
| `/context` | что занимает контекст |
| `/rewind` или Esc Esc | откатить чат и правки файлов |
| `/model`, `/effort high` | сменить модель / глубину рассуждений |
| `/code-review`, `/security-review`, `/simplify` | проверки кода |
| «Какие сабагенты тебе доступны?» | проверить сабагентов (команды `/agents` больше нет; файлы — `~/.claude/agents/`) |
| `/rename` | переименовать чат |
| `/resume` | вернуться к старому чату |

## Новое устройство

1. Установить Claude Code, Git и Node.js, войти в Claude Code своим аккаунтом.
2. Скачать настройку:
   ```
   git clone https://github.com/AboL1uS/claude-setup
   cd claude-setup
   ```
3. Установить:
   - Windows: `powershell -ExecutionPolicy Bypass -File install.ps1`
   - Linux: `bash install.sh`
4. Новый чат → `/mcp` → авторизовать context7.

Скрипт можно запускать сколько угодно раз — он же служит для обновления. Перед изменениями он сохраняет старые настройки в `~/.claude/backup-<дата>/`. Посмотреть, что он сделает, без изменений: `-DryRun` / `--dry-run`.

## Синхронизация между ноутбуками

- Поменял настройку на одном ноутбуке → в этой папке: `backup.ps1` (или `bash backup.sh`), затем `git add -A`, `git commit -m "..."`, `git push`. Проще — попросить Claude в этом проекте.
- На другом ноутбуке: `git pull`, затем `install.ps1` / `install.sh`.

Само приходит через аккаунт claude.ai (ставить не нужно): Figma, Bright Data, Desktop Commander, Fleet, коннекторы Figma и Google Drive.

## Исходный чат

Чат настройки перенесён в этот проект: открыть эту папку в VS Code → история чатов Claude. Его копия (`chat-archive/*.jsonl`) хранится только локально и в GitHub не отправляется.
